# Menedżer projektów OZE – instalatory

Instalatory Windows programu Menedżer projektów OZE. Kod źródłowy jest w prywatnym repozytorium.

**Pobierz najnowszą wersję:** zakładka [Releases](https://github.com/rubiowski-bot/menedzer-projektow-oze-wydania/releases/latest).

Instalacja jest jednorazowa – kolejne wersje instaluje przycisk *Aktualizuj* w programie.
